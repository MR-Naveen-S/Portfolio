# Naveen S — Interactive Portfolio

A stunning, fully interactive single-page portfolio website built with:
- **Three.js** for 3D floating icosahedron geometry
- **GSAP** for smooth scroll-triggered animations  
- **Particle network** with mouse-repulsion physics
- **Animated gradient background** with dynamic grid
- **CSS 3D card tilting** with perspective transforms
- **Typing effect** for hero subtitle
- **Skill bar animations** triggered on scroll
- **Counter animations** for stats

## Features
- 🌊 Animated particle field with connection lines
- 🔮 3D rotating icosahedron with wireframe + torus ring
- 📊 Animated skill proficiency bars
- 🃏 3D-perspective project cards with hover effects
- ✨ Scroll-reveal animations for all sections
- 🖱️ Cursor glow effect
- 📈 Page progress bar
- ⌨️ Typewriter hero text
- 📱 Fully responsive design

## Open
Just open `index.html` in any modern browser.
