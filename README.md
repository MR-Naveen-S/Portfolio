# Naveen S — Engineering & Space Systems Portfolio

Interactive engineering portfolio showcasing systems engineering, Level 1 industrial automation, and deep space & cosmic computing simulations.

**Live Preview**: Simply open [`index.html`](index.html) in any modern browser.

---

## Highlights & Capabilities

- **3D Celestial Engine (Three.js WebGL)**:
  - **01: Terra & LEO Satellite**: Photorealistic Earth with 23.5° axial tilt, continental biome shading, night-side urban lights, custom Rayleigh atmospheric limb glow shader, and an active laser uplink from Sulur Ground Station (11.0°N / 76.9°E) to an orbiting satellite.
  - **02: Gargantua Kerr Black Hole**: Schwarzschild singularity void, upper/lower gravitational lensing arcs (Interstellar relativistic light-bending), and Doppler-beamed accretion disk with 1,400 Keplerian orbital particles.
  - **03: Carina Nebula Nursery**: Volumetric cosmic cloud of 1,800 multi-spectral ionized gas particles ($\text{H-}\alpha$ magenta, $\text{O-III}$ cyan, electric violet) with central young stellar core.
  - Full interactive 3D rotation, mouse wheel zoom, and click-to-ping telemetry.

- **Deep Space Network (DSN) Observatory HUD**:
  - Live carrier frequency, orbital speed, inclination, and ground station telemetry indicators.

- **Audio Synthesizer (Web Audio API)**:
  - Apollo / NASA Quindar intro/outro tones (2,524 Hz / 2,475 Hz).
  - Mechanical switch clack feedback on terminal CLI typing.
  - Cosmic warp sweeps and affirmative command chimes.

- **Interactive Developer Terminal (`[~/] CLI`)**:
  - Fully functional command-line interface supporting `help`, `whoami`, `space`, `pulsar`, `blackhole`, `orbit`, `cgpa`, `skills`, `projects`, `clear`, and `exit`.

- **Comprehensive Content & Engineering Case Studies**:
  - **Academics**: 9.05 CGPA at KPR Institute of Technology, 95% Class XII, 93.3% Class X.
  - **Starlit Steel Automation**: Industrial automation architecture case study (40% latency reduction).
  - **Project Specification Drawer**: Deep architectural breakdowns, tech stacks, and benchmarks for Python OCR, Covid-19 Analytics Dashboard, Plantfix Figma UI/UX, Campity, and Billing Engine.

## Tech Stack

- **Graphics**: Three.js (WebGL, Custom GLSL Shaders, Canvas Textures)
- **Audio**: Web Audio API (Procedural Oscillators & Envelope Generators)
- **Typography**: Syne, DM Serif Display, DM Sans, JetBrains Mono
- **Deployment**: Pure zero-dependency client-side HTML5/CSS3/ES6
